Foundations

Copilot is more than autocomplete

One assistant, several surfaces. Each surface is a different entry point to the same models.

⌨️
Editor

Code completions

Inline suggestions & next-edit. Fast, and free — they don't consume AI credits.

💬
Chat

Ask / Edit

Conversational help and multi-file edits, scoped to your selection or files.

🤖
Agent

Agent mode

Plans, edits, runs tools across many steps. Powerful — and token-hungry.

☁️
Cloud

Coding agent

Runs on GitHub.com, opens pull requests from an issue or a prompt.

The same guidance steers all of them

Custom instructions, prompt files and chat modes you commit to a repo apply in the editor, the CLI, and the cloud agent. Write good context once → every surface benefits.

Basic concepts

The words behind the magic

🧠 LLM (model)

A large language model that predicts the next token. Different models trade off speed, quality, and cost.

📝 Prompt

Your instruction + everything attached (system rules, files, history). This is what the model reads.

🔡 Token

The unit models read and write — roughly ~4 characters of English (¾ of a word). You're billed per token.

🪟 Context window

The model's working memory for one request (e.g. 128k–200k tokens). Everything must fit; overflow gets dropped.

💳 AI credit

The billing unit for agent/chat usage. 1 credit = $0.01. Each plan includes a monthly pool.

🗂️ Context

What you give the model to reason over: selections, files, instructions. More isn't better — relevant is better.

How tokens work

Everything is tokens

Models don't see words or characters — they see tokens. Roughly 1 token ≈ 4 characters ≈ ¾ of a word.

Input tokens

What you send

System prompt, your message, attached files, tool definitions, and the whole conversation history.

Output tokens

What it generates

The reply. 4–8× more expensive than input — verbosity you didn't need is money you spent.

Cached tokens

Reused prefix

A repeated prefix (rules, tools, context) can be cached and billed at ~10% of input. Not guaranteed.

Billing

AI credits, explained

Since June 2026, Copilot bills agent & chat usage by tokens, drawn from a monthly pool of AI credits. 1 credit = $0.01.

  • ✓
    Free & unlimited: code completions and next-edit suggestions never consume credits.
  • $
    Credits are spent on chat, agent mode, and the cloud coding agent — priced per token, per model.
  • ≈
    Each plan includes a pool roughly equal to its price: Pro ~1,000 · Business ~1,900 · Enterprise / Pro+ ~3,900 credits/mo.
  • ↻
    "Auto" model selection can apply a small discount — a good default when you don't need a specific model.

Choosing a model

Right model for the job

On large workloads the cost gap between models can be 20×+. Match the model to the difficulty of the task.

💚 Light / mini

≈ $0.25 in · $2 out

Cheap & fast. Great default.

  • Boilerplate & scaffolding
  • Q&A, explanations
  • Simple refactors & renames
  • Commit messages, docs

💙 Balanced

≈ $2–3 in · $12–15 out

Everyday agent work.

  • Multi-file edits
  • Test generation
  • Moderate debugging
  • Most day-to-day tasks

🧡 Premium / Opus

≈ $5 in · $25–30 out

Save for the hard stuff.

  • Deep reasoning / architecture
  • Gnarly cross-cutting bugs
  • Large refactors
  • When cheaper models fail

Rule of thumb: start cheap, escalate only when the model actually struggles. Use Auto when unsure — it picks a reasonable model and may discount the run.

Token optimization

The playbook

Fewer, better-targeted tokens usually means better answers — not just cheaper ones.

  • 1
    New chat per task. History is re-billed every turn.
  • 2
    Scope context — a selection or #file, not the whole repo.
  • 3
    Force concise output via instructions / a "concise" mode.
  • 4
    Preprocess big docs — PDF/DOCX → trimmed Markdown.
  • 5
    Keep diffs small — format-on-save, tidy edits.
  • 6
    Reuse prompt files & chat modes instead of re-typing.
  • 7
    Right-size the model — cheap by default.
  • 8
    Exclude junk (node_modules, dist) from search/context.

Pro tip — PDF → Markdown: convert bulky documents with Microsoft's open-source markitdown before using them as context. A 40-page PDF becomes a few KB of relevant Markdown.

Agent & auto mode

Power with a seatbelt

Agent mode can edit files and run commands across many steps. "Auto mode" = letting those tool calls run without approval.

✓ Reasonable to auto-approve
  • ✓Repo is under version control (easy to revert)
  • ✓Low-risk tasks: formatting, docs, tests
  • ✓Read-only commands, and you're watching
⛔ Keep approvals ON
  • !Destructive / irreversible commands
  • !Anything touching secrets or production
  • !You're not watching the run

Wrap-up

Five things to remember

  • 1
    Everything is tokens — and you pay for the whole context window on every agent loop.
  • 2
    Output costs 4–8× input. Concise instructions are the highest-ROI optimization.
  • 3
    Credits = tokens × model. Completions are free; agent runs on premium models cost most.
  • 4
    Scope context, new chat per task, preprocess big docs. Relevant beats large.
  • 5
    Operationalize it — commit instructions, prompts & modes so the whole team benefits.
