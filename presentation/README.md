# 🖥️ Session presentation

A self-contained HTML slide deck for the ~30-minute talk that opens the workshop.

## Open it

Just double-click **`index.html`** (or open it in any browser). No build step, no
internet, no dependencies — everything is inlined so it works offline during a live session.

## Navigate

| Action | Keys |
| --- | --- |
| Next / previous slide | `→` / `←` (also `Space`, `PageUp/Down`) |
| First / last slide | `Home` / `End` |
| Fullscreen | `F` |
| On screen | arrow buttons (bottom-right), swipe on touch |

## What it covers

1. Title (presenters)
2. Agenda
3. Copilot surfaces (more than autocomplete)
4. The three configuration levels
5. Basic concepts / glossary
6. What is a token
7. Context window & tokens (per-loop billing)
8. Output economics (4×–8×) + pricing table
9. AI credits explained
10. Choosing a model
11. Token optimization playbook
12. Agent & auto mode
13. Copilot across the lifecycle
14. Reusable repo assets
15. Challenges & points
16. Key takeaways
17. Thank you

## Notes

- Pricing/credit figures are **illustrative** and change often — verify against
  GitHub Copilot → *Models and pricing* before quoting exact numbers to a customer.
- To export to PDF: open in Chrome → Print → *Save as PDF* (landscape). Advance one slide
  per page if you want individual pages.
