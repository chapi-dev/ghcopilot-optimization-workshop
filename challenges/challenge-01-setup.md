# Challenge 01 · Setup & extensions (10 pts)

**Goal:** get a working, token-friendly Copilot setup in VS Code.

Background: [docs/01-setup.md](../docs/01-setup.md)

## Steps

1. Open this repo folder in VS Code.
2. Install the **recommended extensions** (prompt, or *Extensions: Show Recommended Extensions*).
3. Sign in to Copilot; open Chat with `Ctrl+Alt+I`.
4. Confirm the customization files are picked up:
   - Chat mode dropdown shows **Concise** and **Planner**.
   - Typing `/` in Chat lists `token-diet`, `pr-description`, `doc-to-markdown`.

## Done when

- [ ] Recommended extensions installed.
- [ ] Copilot Chat responds.
- [ ] Custom chat modes and prompt files appear in the UI.

## ⭐ Stretch (+5)

Copy the three highest-impact keys from `.vscode/settings.json` into your **User** settings so
concise + instruction files apply in **every** project, not just this repo.
