# Challenge 06 · Copilot across the lifecycle (20 pts)

**Goal:** use Copilot for a non-coding lifecycle task and capture it as a reusable asset.

Background: [docs/06-lifecycle.md](../docs/06-lifecycle.md)

## Pick ONE track (or do several for bonus)

### Track A — Review

1. Make a small change in this repo and stage it.
2. Run `/pr-description` to generate a PR description from the diff.
3. Confirm it's accurate and terse.

### Track B — Release

1. Add commit-message instructions to `.vscode/settings.json`
   (`github.copilot.chat.commitMessageGeneration.instructions`).
2. Stage a change and generate a commit message from the Source Control view.
3. Confirm it follows your convention.

### Track C — Ops/support

1. Paste a **short, relevant** slice of a stack trace or log.
2. Ask Copilot (Concise mode) to explain the likely cause and a fix.
3. Save the winning prompt as a new prompt file for the team.

## Done when

- [ ] You completed at least one track.
- [ ] The output is usable as-is.
- [ ] You captured something reusable (prompt file, instruction, or setting).

## ⭐ Stretch (+5 each, max +10)

Complete a second and third track.

**Points:** 20 (+10 stretch)
