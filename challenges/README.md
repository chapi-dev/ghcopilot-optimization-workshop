# 🏆 Challenges

Hands-on challenges for the workshop. Work in **VS Code**. Each challenge lists **points**, a
goal, steps, and a "done when" check. You don't have to do them all — pick what's useful.

## How points work

- Each challenge shows a base point value.
- ⭐ **Stretch goals** add bonus points.
- Track your score in [`SCOREBOARD.md`](SCOREBOARD.md).
- Suggested target for the session: **60+ points**.

## Rules

- **No MCP.** If something seems to need it, use the MCP-free path in the docs.
- Keep prompts **scoped** (selection / single file first).
- Prefer this repo's **prompt files** and **chat modes** over retyping.
- All content you add stays in **English**.

## Tips

- Stuck? The matching `docs/` page has the background for each challenge.
- Use the **Concise** chat mode and `/token-diet` to keep answers (and token usage) small.
